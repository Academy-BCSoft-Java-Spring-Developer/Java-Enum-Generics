# Java Enumerations & Generics

This repository contains practical implementations and exercises designed to explore type safety, domain modeling, and reusable code patterns in Java using Enumerations (`enum`) and Generics.

---

## 📌 Topics Covered

### 1. Java Enumerations (`enum`)
- **Type-Safe Constants**: Replacing arbitrary constants and integers with robust, strongly typed enum structures.
- **Enums with State & Behavior**: Adding custom fields, parameterized constructors, and instance methods to enums.
- **Built-in Methods & Utilities**: Working with standard methods such as `values()`, `valueOf()`, and `ordinal()`.
- **Advanced Enum Features**: Implementing interfaces in enums and defining constant-specific method implementations.

### 2. Java Generics
- **Generic Classes & Interfaces**: Building reusable, decoupled components that operate across diverse data types while maintaining compile-time type safety.
- **Generic Methods**: Implementing standalone methods with independent type parameters `<T>`.
- **Bounded Type Parameters**: Restricting allowed types using upper bounds (`<T extends Number>`) to enforce specific API contracts.
- **Wildcards (`?`)**: Managing covariance and contravariance with unbounded, upper-bounded (`? extends T`), and lower-bounded (`? super T`) wildcards.
- **Type Erasure**: Understanding compiler behavior, runtime limitations, and generic type erasure mechanics.
